# RAG PoC → 정식 제품 로드맵

> 다관점 설계 패널(MVP우선 / 리스크·거버넌스우선 / 데이터흐름우선 → 완결성 비평 → 종합)로 도출.
> 전제: 온프렘, SR(서비스요청) 지원, Gemini 무료티어 쿼터가 상시 병목.

## 결론 — "메인 후보 4개" 재판정

| 후보 | 판정 | 이유 |
| --- | --- | --- |
| RAG | ✅ 메인 (단, 분해됨) | 단일체가 아니라 **`ACL 검색코어 + 근거강제 답변`** 엔진 위에 SR ①②③④가 얹히는 구조. 진짜 헤드라인 가치는 SR 4서비스, RAG는 그들이 공유하는 엔진 |
| ETL | ✅ 메인 | SR 전부가 쓰는 **데이터·출처·권한·증분 메타**가 나오는 척추 (P0는 최소 배치, 증분은 P1) |
| 단어사전 | ❌ → 보조 | 검색·엔티티 정규화, 동음이의(CM=ConfigMap/Change Mgmt) 해소로 정확도를 올리는 **부스터**. 사용자 가치를 직접 주는 제품 아님 |
| 관측/쿼터 | ⚠️ 반만 | **'쿼터 가드(LLM 게이트웨이)'는 P0 필수 인프라**(없으면 적재조차 완주 불가) / **'대시보드'는 P2 보조** |

**빠져 있던 메인**: SR ①②③④ 서비스 자체 + 그들이 공유하는 검색코어·근거답변층.

## 구성요소 분류

### 메인 (사용자 가치 / 공유 엔진)
- **ETL 인제스트 오케스트레이터** — 수집→정제→저장, 반입 시점에 출처·권한·증분·민감도 메타 확정
- **ACL 인지 검색 코어** — 질의자 권한 문서집합으로 필터한 검색 (SR 전부의 공유 엔진 = 진짜 'RAG 메인')
- **근거강제 답변 서비스** — page URL/section/issue key 인용 강제, 근거 없으면 거부/플래그
- **SR① 고객문의 사전답변** / **SR② 담당자추천** / **SR③ 장애 원인분석** / **SR④ 문서품질 개선**

### 보조 (품질·안전·운영)
용어·약어 사전, 온톨로지·스키마 거버넌스, 증분 CDC, ACL 동기화/질의필터, 삭제·권한취소 교차퍼지,
Secret/PII 리댁션, 인젝션 방어+faithfulness 가드, 로컬 리랭커, 시맨틱 캐시, 평가 골든셋,
ACL 누출 테스트, 피드백·로그 수집, 검토 UI, 버전 레지스트리, 재색인·마이그레이션, 관측 대시보드, 온프렘 LLM 이관

### 인프라
Podman 런타임, Qdrant(+임베딩 모델 버전 고정), Neo4j, **LLM 게이트웨이·쿼터 가드**, **로컬 임베딩 모델**,
**문서 메타데이터/상태 레지스트리**, 질의자 신원해소(SSO/LDAP), API 게이트웨이·인증, 감사·접근 로깅, DR 백업/복구

## 단계별 로드맵

### P0 — 신뢰 기반 + 첫 가치
- **목표**: Vector 단독으로 `적재 → ACL 검색 → 근거 답변`이 파일럿 사용자에게 안전하게 완주됨을 증명.
- **빌드**: Podman · Qdrant · 로컬 임베딩 · LLM 게이트웨이 · 메타 레지스트리 / 커넥터 · 청킹 · Secret 스크럽 · ETL / ACL 동기화 · 신원해소 · 질의필터 / **검색코어 · 근거강제 답변** / **SR② 담당자추천 → SR① 사전답변** / API 인증 · 골든셋(수동)
- **왜**: 로컬 임베딩·쿼터 가드가 없으면 초기 코퍼스 적재 자체가 불가. 실사용자 질의를 받는 순간 ACL·신원·Secret은 하드 제약. ②는 `generate_content`를 거의 안 써 20/day 쿼터벽을 우회하며 가치를 먼저 검증.
- **완료기준**: 파일럿 코퍼스 로컬 임베딩으로 완주 적재 / 사용자가 자기 권한 문서로만 ② 실사용(ACL 누출 0) / ①은 인용 강제+수동 검증분만 노출 / 쿼터 가드가 예산 내 안정 구동.

### P1 — 지속가능 + 개선루프
- **목표**: 증분으로 최신성·쿼터 절약, 정확도·측정·개선 루프, 온프렘 LLM 폴백 확보.
- **빌드**: 증분 CDC · 권한취소 퍼지 / 리랭커 · 시맨틱 캐시 / 용어사전 · 인젝션·근거 가드 / 평가 골든셋 · ACL 누출테스트 · 피드백 / 버전 레지스트리 · 온프렘 LLM 폴백
- **왜**: 전체배치 재임베딩 비용을 CDC로 해소. 리랭커·캐시는 쿼터를 안 쓰고 정밀도·처리량을 올리는 값싼 레버. 골든셋·누출테스트는 확장 전 게이트("측정 없는 확장 금지").
- **완료기준**: 증분만으로 최신성 유지 / 골든셋 기준선 확보 / ACL 누출테스트 자동 통과 / 로컬 LLM 폴백 동작.

### P2 — 그래프 · 원인분석
- **목표**: 검증된 Vector 코어 위에 Graph/Hybrid를 얹어 ③ 제공, 운영 가시성 확보.
- **빌드**: Neo4j · 온톨로지 거버넌스 · Graph추출 · Hybrid / **SR③ 장애 원인분석** / 관측 대시보드 · 검토 UI
- **왜**: Graph LLM 추출은 쿼터를 크게 태워 MVP에서 후퇴. 통제 온톨로지 없이 추출하면 그래프가 오염돼 ②③ 신뢰도 하락 → 스키마 거버넌스 선행.
- **완료기준**: ③가 유사 장애 이력+관계 그래프로 원인 후보를 근거와 함께 제시 / Graph 추출이 예산 내 증분 재추출.

### P3 — 완성 · 온프렘 전환
- **목표**: ④ 제공, 무중단 재색인으로 온프렘 LLM 전면전환, 손실복구 안전망.
- **빌드**: **SR④ 문서품질 개선** / 무중단 재색인 · 온프렘 LLM 전면전환 · DR
- **왜**: ④는 평가·사전·검색·그래프 성숙이 전제라 마지막. 온프렘 전환은 전량 재적재를 수반하므로 버전드 컬렉션·블루그린 없으면 전환이 곧 검색 붕괴.
- **완료기준**: ④가 노후/공백/중복/용어불일치 탐지·제안 / 임베딩 전환을 무중단 재색인으로 검증 / DR 복구 리허설 통과.

## 핵심 의존 척추

1. **LLM 게이트웨이 + 로컬 임베딩** → 모든 적재·검색의 물리적 전제. Gemini 무료티어(생성 20/day + 임베딩 별도)로는 초기 전체 코퍼스 임베딩이 불가.
2. **문서 메타 레지스트리(단일 진실원)** → 출처·ACL·증분이 전부 여기 의존. 색인 전에 못 잠그면 사후 복구 불가.
3. **ETL 반입 시점에 ACL·Secret 스크럽·증분키를 *동시* 확정** → 한번 임베딩되면 비가역(유출·권한).
4. **ACL 동기화 + 신원해소(SSO/LDAP)** → 실사용자 질의를 받는 순간 하드 제약. 검색코어 노출과 동시(P0).
5. **검색코어 + 근거답변** → SR ①②③④ 모두 이 공유 코어 위에 얹힘. 개별 SR 기능보다 반드시 선행.
6. **평가 골든셋** → ①③④의 사용자 노출·확장 게이트.
7. **임베딩 모델 버전 고정** → 적재/질의 모델 불일치 시 조용한 검색 붕괴. 온프렘 전환 시 버전드 컬렉션·무중단 재색인이 전제.

## 최대 리스크

- **쿼터**: Gemini 무료티어가 실사용 검증의 최대 병목. 완화 = ②(생성 미소비) 선행 + 쿼터 가드 캐시/예산 + 코퍼스 축소, 궁극적으로 **온프렘 LLM 전환**.
- **권한 유출**: ACL 상속/동기화 지연 시 권한 없는 문서 노출 = 보안사고. 반입 시 restriction+그룹 캡처, 질의 시 재검증, 불명확하면 제외.
- **근거성(hallucination)**: 인용 강제 + 근거없음 시 거부 + 골든셋 측정 없으면 신뢰 붕괴.
- **동음이의 약어**: CM 등 오해석으로 오검색·내부정보 오노출 → 사전의 문맥 해소가 정확도·보안에 직결.
